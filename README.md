# Radio Lab

Интерактивная лаборатория цифровой радиосвязи. Первый эксперимент — **QPSK: комплексная огибающая I/Q** с синхронными временными графиками и фазовой плоскостью.

## Запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Откройте локальный адрес, который покажет Vite. Проверка формул: `npm test`. Продакшен-сборка: `npm run build`.

## QPSK

- Четыре редактируемых двухбитных символа; Gray-кодирование `00 ↗`, `01 ↖`, `11 ↙`, `10 ↘`.
- Единое время для двух осциллограмм и вектора комплексной огибающей.
- Прямоугольные символы или Raised Cosine (RC) с регулируемым roll-off β.
- Play/Pause, скраббинг, скорость воспроизведения и URL с параметрами эксперимента.
- Все вычисления выполняются **в браузере**, без бэкенда.

В демонстрации приняты единичная амплитуда QPSK и нормированное время `t/Ts`. При RC временная последовательность периодически повторяется; отсчёты соответствуют выходу идеализированного **RC-фильтра Найквиста**, а не физической RRC-цепочке передатчика/приёмника. Эта оговорка важна при изучении переходных процессов.

## GitHub Pages

Сайт подготовлен для публикации по адресу `https://dreamworkerln.github.io/radio-lab/`. В `vite.config.ts` установлен `base: '/radio-lab/'`.

1. В GitHub откройте `Settings → Pages → Build and deployment → Source` и выберите **GitHub Actions**.
2. Workflow `.github/workflows/deploy.yml` автоматически запускается при изменении ветки `master` (или вручную из Actions).
3. После успешного workflow сайт станет доступен по указанному адресу.

Проект: React + TypeScript + SVG + Vite. Планируются самостоятельные модули BPSK, QAM, фильтров и LoRa.
